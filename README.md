# Data Warehouse & Visualization Project

## 📌 Overview

This project involves designing and implementing a data warehouse, followed by building interactive visualizations. The architecture is modeled using draw.io, integrating multiple data sources into a structured and analysis-ready format.

---

## 🏗️ Data Architecture

* Designed using **draw.io**
* Follows a structured pipeline:

  * Data Sources → Staging → Data Warehouse → Reporting Layer
* Ensures scalability, consistency, and efficient querying

---

## 📂 Data Sources

* CSV files
* ERP system

---

## 🧹 Data Processing

* Data is cleaned and standardized before loading
* Ensures consistency in formats, naming conventions, and data types

---

## 🛠️ Tools & Technologies

* **SQL** – Data modeling, transformation, and warehousing
* **Power BI** – Data visualization and dashboard creation

---

## 📊 Deliverables

* Data warehouse schema (SQL-based)
* Architecture diagram (draw.io)
* Interactive dashboards (Power BI)

---

## 🎯 Objective

To transform raw data into meaningful insights by building a reliable data warehouse and delivering clear, actionable visualizations.
